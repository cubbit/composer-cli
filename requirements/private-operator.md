# Private Dashboard CLI

All the operations for the public CLI plus

- `ds3-composer operator create/new --name=<name> --email=<email> --password=<password>`: to create a new operator from CLI

## Distributor

- `ds3-composer distributor create/new --name=<name> --email=<email> --password=<password>`: to create a new distributor
- `ds3-composer distributor list/ls`: to list distributors
- `ds3-composer distributor remove/rm <distributor-id>`: to delete a distributor
- `ds3-composer distributor assign-tenant --tenant-id=<tenant-id> --coupon-id=<coupon-id>`: assigns a tenant to a coupon
